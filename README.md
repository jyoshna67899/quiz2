# QuizMaster CRT — Degree Placement Practice

A GitHub-Pages-only placement practice platform for degree students.

## Question bank
- English: **1,200+**
- General Knowledge: **1,200+**
- Programming Languages: **1,200+**
- CRT Aptitude: **1,200+**
- Total: **4,800+ questions**
- Difficulty: Easy, Medium, Hard
- Company-style filters: TCS, Infosys, Wipro, Accenture, Cognizant, Capgemini, Deloitte, IBM, Amazon, Microsoft
- Test sizes: 10, 25, 50, 100

## Features
Timed tests, randomized selection, subject/difficulty/company filters, instant feedback, correct answer, explanation, hint, supportive messages after mistakes, score, accuracy, best score, history, LocalStorage progress and dark mode.

## Company question disclaimer
Company labels indicate **placement-practice style** only. These are not claimed to be official, leaked or exact interview questions from any company. Actual assessments change.

## Deploy on GitHub Pages
Upload `index.html`, `style.css`, `app.js`, `questions.js`, `README.md` and `.gitignore` directly into the repository root.
Then open **Settings → Pages → Deploy from a branch → main → /(root) → Save**.
